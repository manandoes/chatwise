# The dashboard

Everything behind the login: the overview, the customer's single bot, their live
inbox, leads, WhatsApp connection, knowledge base, campaigns, analytics, billing
and settings.

There is deliberately no "add another bot" or "add another connection" screen —
an account runs one bot on one connection (docs/PRD.md §3.1).

Built from **Phase 4** onwards. See docs/Phases.md.
